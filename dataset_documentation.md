# Dataset documentation

The analysis uses the public Kaggle dataset [Campaign Effectiveness](https://www.kaggle.com/datasets/sanak2000/campaign-effectiveness). It was selected because it contains campaign-level impressions, clicks, conversions, cost, and revenue across ten marketing channels, supporting all required funnel and financial metrics and substantially more than the minimum number of comparison groups. Kaggle describes the 5,500 records as simulated, so they are suitable for demonstrating the statistical workflow but not for making claims about real company performance.

The source workbook has 5,500 rows and 16 columns. Its ten channels contain 523–576 campaigns each. There is no date column, so no date range can be reported and each row is treated as one campaign execution rather than one day. The raw fields are campaign ID and manager, channel, creative format, impressions, clicks, conversions, cost, revenue, retention rate, average order value, annual purchase frequency, launch-day weather, customer lifespan, color theme, and discount rate. Exact source and cleaned schemas, data types, missing-value counts, channel names, and sample sizes are recorded in `tables/data_quality_summary.json`.

Cleaning standardizes column names, coerces numeric fields, removes duplicate campaign IDs, drops rows missing required funnel or financial fields, and rejects impossible funnels or non-positive cost. This dataset had no duplicates, missing required values, or invalid rows, so all 5,500 records were retained. The script calculates CTR, conversion rate, CPA, ROAS, profit, and profit margin with zero denominators and infinite results converted to missing values. The prepared 22-column output is `marketing_data.csv`; the raw workbook is preserved unchanged at `data/raw/campaign_effectiveness.xlsx` (SHA-256 `e23c610b21e4e6878b8b31709904f859994ae8a03768d1823cacef394b63c46b`).
